# 🏛️ Mini-portail administratif de la Commune de Mboro

## 🌐 Lien du site déployé  
🔗 [https://phina-d.github.io/mini-portail/](https://phina-d.github.io/mini-portail/)

---

## 📝 Description du projet  
Ce mini-portail a été conçu pour la **Commune de Mboro** afin d’offrir un espace numérique moderne, accessible et transparent à ses citoyens.  
Il présente les élus, les conseillers municipaux, les programmes, les services, et bien d’autres rubriques administratives.

Le site est **responsive**, **en mode clair/sombre**, et dispose d’un design professionnel adapté aux institutions publiques.

---

## ⚙️ Technologies utilisées  
- **React.js + Vite** ⚡  
- **React Router DOM** pour la navigation entre les pages  
- **Tailwind CSS** pour le style et la responsivité  
- **Leaflet / React-Leaflet** pour la carte interactive  
- **React Icons & Slick Carousel** pour les icônes et les carrousels  
- **GitHub Pages** pour le déploiement

## 🧩 Installation en local  

1️⃣ **Cloner le dépôt**  

git clone https://github.com/Phina-d/mini-portail.git
cd mini-portail
```

2️⃣ **Installer les dépendances**  

npm install
```

3️⃣ **Lancer le serveur local**  

npm run dev
```
➡️ Ouvrez ensuite le lien fourni (souvent http://localhost:5173).

---

## 🚀 Déploiement sur GitHub Pages  

1️⃣ **Build du projet**  

npm run build
```

2️⃣ **Déploiement automatique**  

npm run deploy
```

Ce script :
- génère le dossier `dist/`,
- et publie automatiquement le site sur GitHub Pages  
  à l’adresse 👉 [https://phina-d.github.io/mini-portail/](https://phina-d.github.io/mini-portail/)
